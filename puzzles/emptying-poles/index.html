The formal proof

Setup

Label the three poles and let their disc counts be \(a \le b \le c\). The move is: choose a "receiver" pole holding \(y\) discs and a "donor" pole holding \(\ge y\) discs; transfer \(y\) discs from donor to receiver, so the receiver now holds \(2y\). (A pole already at \(0\) means we are done, so assume all counts are \(\ge 1\).)

I'll prove the statement by infinite descent on the minimum pile: I'll show that whenever the smallest pile has \(a \ge 1\) discs, a finite sequence of legal moves produces a configuration whose smallest pile has strictly fewer than \(a\) discs. Since the minimum is a non-negative integer that strictly decreases, it must eventually reach \(0\) — an empty pole.

One round: shrinking the minimum

Let the piles be \(a \le b \le c\) with \(a \ge 1\). Divide:

\[b = qa + r,\qquad q = \lfloor b/a\rfloor \ge 1,\qquad 0 \le r < a,\]

and write \(q\) in binary: \(q = \sum_{i=0}^{k}\epsilon_i 2^i\) with \(\epsilon_i\in\{0,1\}\) and leading bit \(\epsilon_k = 1\) (so \(2^k \le q\)).

The moves. Always use pile \(A\) (the smallest) as the receiver. Since \(A\) starts at \(a\) and is doubled each step, before step \(i\) it holds exactly \(2^i a\). For \(i = 0,1,\dots,k\) in order, double \(A\) once, taking the required \(2^i a\) discs:

  • from pile \(B\) if \(\epsilon_i = 1\),
  • from pile \(C\) if \(\epsilon_i = 0\).

Why every move is legal. Picture \(B\)'s starting count as one chunk of size \(a\cdot 2^j\) for each set bit of \(q\), plus the leftover \(r\):

\[b = r + \sum_{j:\,\epsilon_j=1} a\cdot 2^j.\]

Processing the bits low-to-high turns off \(q\)'s set bits one at a time: when \(\epsilon_i = 1\) we strip the chunk \(a\cdot 2^i\) from \(B\); when \(\epsilon_i = 0\) there is no such chunk in \(B\), so \(A\) doubles from \(C\) instead. After the round every set bit of \(q\) has been cleared from \(B\), leaving exactly \(r < a\).

Two things to check:

1-bit (\(\epsilon_i = 1\)). Earlier steps have only touched chunks at lower indices than \(i\), so the chunk \(a\cdot 2^i\) is still sitting in \(B\) untouched. Take it. ✓

0-bit (\(\epsilon_i = 0\)). The leading bit \(\epsilon_k = 1\) forces \(i \le k-1\), so \(C\) started with \(c \ge b \ge a\cdot 2^k \ge 2\cdot a\cdot 2^i\). By now \(C\) has given up at most \(a(1 + 2 + \cdots + 2^{i-1}) = a(2^i - 1) < a\cdot 2^i\). So \(C\) still holds more than \(a\cdot 2^i\). ✓

Termination

Each round replaces the current minimum \(a\ge 1\) by a new minimum \(\le r < a\). A strictly decreasing sequence of non-negative integers reaches \(0\) in finitely many rounds, and a minimum of \(0\) is an empty pole. \(\blacksquare\)

Quick check

Start \((1,5,6)\). Here \(a=1,b=5,c=6\), \(q=5=(101)_2\), \(r=0\):

  • \(i=0\) (\(\epsilon_0=1\)): take \(1\) from \(B\) → \((2,4,6)\)
  • \(i=1\) (\(\epsilon_1=0\)): take \(2\) from \(C\) → \((4,4,4)\)
  • \(i=2\) (\(\epsilon_2=1\)): take \(4\) from \(B\) → \((8,0,4)\)

A pole is emptied, exactly as the descent predicts.
